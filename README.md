# Ozyegin University Autonomous Suturing Project

Static project website for the Cognitive Robotics Lab and Robotics Lab at Özyeğin University.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, and folder **/ (root)**.

Site URL: https://ozurobotics.github.io/suture-project/

## Editing

- `index.html`: project description, papers, and team profiles.
- `styles.css`: layout, typography, and responsive styles.
- `script.js`: add YouTube video IDs and titles to `projectVideos` to display the video section.
- `assets/`: photos, project illustrations, and BibTeX downloads.

No build step is required. Open `index.html` directly or run `python3 -m http.server 8000` from this directory.

Content comes from the supplied project PDF/DOCX. Publication dates and “to appear” statuses reflect those documents. Google Fonts are optional; system fonts are used if unavailable.
